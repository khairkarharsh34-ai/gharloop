# Ghar Loop brand kit

House with three neighbours inside, and "Gharloop" where the "oo" is an infinity loop (the society, always connected).

| File | Use |
|---|---|
| `gharloop-logo.svg` / `png/gharloop-logo.png` | Main logo with tagline, on white or cream |
| `gharloop-logo-white.svg` / `png/…-white.png` | Same, for neem-green or dark backgrounds |
| `gharloop-logo-horizontal(.svg/-white)` | One-line logo: website header, letterhead, app header |
| `gharloop-icon.svg` | House mark only (stickers, favicon on light) |
| `gharloop-app-icon.svg` / `png/gharloop-app-icon.png` | App icon, WhatsApp / Instagram profile picture |
| `gharloop-app-icon-cream.svg` | Light version of the app icon |

The SVGs are vector, so they can be printed at any size (send these to printers). Text is converted to shapes, so no font is needed.
